# Open-House-Track-3

เอเจนต์ขายกาแฟ `optimized-v2` และตลาดจำลองออฟไลน์ ใช้ Node.js (ทดสอบด้วย v24) และไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## เดโมเว็บสำหรับนำเสนอ

1. รัน `.\demo.cmd` และเปิด [ตลาดจำลอง](http://127.0.0.1:8787/trade)
2. เลือกความเร็วหรือ `กดไปรอบเอง` แล้วกด **เริ่มเดโม** เอเจนต์จะประเมินล็อตและยื่นซองเองผ่าน HTTP
3. ดูคำขอ API ซอง ผลจับคู่ และ PR เมื่อปิดตลาด ปุ่ม **เริ่มใหม่** จะคืนเกมสู่จุดเริ่มต้นด้วย seed เดิม

เดโมมีรอบซ้อม P1 และรอบนับคะแนน R1–R15 เทศกาลอยู่ที่ R6–R8 และความต้องการลดลงที่ R13–R15 ค่าเริ่มต้นของตลาดรับการเชื่อมต่อจากเครื่องตัวเอง ใช้ข้อมูลจำลอง และไม่ต้องใส่ team key หรือเปิด LLM

API ทุกเส้นทางอยู่ใต้ `/v1` ตามชื่อในคู่มือ starter รวมถึง `GET /v1/calendar`, `GET /v1/state`, `POST /v1/appraisals`, `POST /v1/offers:batch` และ `GET /v1/results?round=R1` แบบซองและผลจับคู่ใช้ฟิลด์ที่ starter อ่านได้ ค่า TV และเพดานผู้ซื้อเป็นค่าของตลาดจำลอง ผลเดโมแสดง PR กับคะแนนประเมินเต็ม 20 คะแนน เพราะคะแนน PR เต็ม 80 ต้องอิง PR สูงสุดของทีมจริงในตลาดเดียวกัน

หากต้องการใช้เอเจนต์ภายนอก เปิดเซิร์ฟเวอร์ด้วย `.\demo.cmd --external` แล้วชี้ Market URL มาที่ `http://127.0.0.1:8787` ฝั่งเซิร์ฟเวอร์รับคำขอโดยไม่ตรวจ Authorization หากใช้ Python starter เดิมที่บังคับอ่านตัวแปร `TEAM_KEY` ให้ใช้ข้อความใดก็ได้ เช่น `local-demo` และตั้ง `USE_LLM=0`

## ใช้คนละเครื่องผ่านเครือข่าย

1. เครื่องตลาดรัน `.\demo.cmd --network --external` บน Windows หรือ `node demo/server.js --network --external` บน macOS เครื่องนี้จะพิมพ์ URL ที่ขึ้นต้นด้วย `LAN:` ใช้เบราว์เซอร์บนเครื่องใดในเครือข่ายเดียวกันเปิด URL นั้น
2. บน Mac ที่จะรันเอเจนต์ เปิด Terminal ในโฟลเดอร์โปรเจกต์ คัดลอก `.env.example` เป็น `.env` แล้วใส่ IP ที่เครื่องตลาดพิมพ์ออกมา เช่น `MARKET_URL=http://192.168.1.40:8787` ใช้ URL ถึงพอร์ต
3. รัน `node demo/agent-client.js` บน Mac และเปิดหน้าเว็บที่ `http://192.168.1.40:8787/trade` เมื่อหน้าเว็บแจ้งว่าเอเจนต์เชื่อมต่อแล้ว ให้กด **เริ่มเดโม** หากปิดตลาดแล้วจะเล่นอีกเกม ให้รีเซ็ตตลาดและรันเอเจนต์อีกครั้ง

`--external` ปิดเอเจนต์ที่ฝังอยู่ในเครื่องตลาดเพื่อให้ Mac เป็นผู้ยื่นซอง โหมดเครือข่ายนี้เปิดให้ทุกเครื่องที่เชื่อมถึงตลาดกดควบคุมเดโมได้ จึงเหมาะกับ LAN หรือฮอตสปอตส่วนตัว หากเข้าผ่าน IP ไม่ได้ ให้ตรวจว่าอุปกรณ์เชื่อมถึงกันและไฟร์วอลล์เครื่องตลาดอนุญาตการเชื่อมต่อเข้าพอร์ตที่ใช้

## เริ่มรัน

เปิดโฟลเดอร์นี้ใน VS Code แล้วพิมพ์ใน Terminal หรือดับเบิลคลิก `run.cmd` ใน File Explorer

```powershell
.\run.cmd
```

คำสั่งนี้จำลอง 100 เกม เกมละ 15 รอบ ด้วย seed เริ่มต้น 81000 และบันทึกสรุป PR กับผลขายรายรอบลง `result.json` ในโฟลเดอร์นี้ การรันซ้ำด้วยค่าเดิมให้ผลเดิมและเขียนทับไฟล์นี้

กำหนดจำนวนเกม จำนวนรอบ (8 หรือ 15) seed กลยุทธ์ และชื่อไฟล์ผลได้เอง เช่น

```powershell
node market_sim.js 100 15 92000 optimized-v2 result-92000.json
```

## ไฟล์หลัก

- `agent.js` เลือกล็อต ผู้ซื้อ ราคา และจำนวนกระสอบที่จะเสนอขาย
- `market_sim.js` สร้างตลาดจำลอง ตัดสินผลเสนอขาย และคำนวณ PR รวมมูลค่าขายซาก
- `optimized-policy-v2.json` เก็บค่ากลยุทธ์ล่าสุดของเอเจนต์สำหรับตลาดจำลอง
- `optimize.js` และ `optimize_v2.js` ใช้ค้นหาค่ากลยุทธ์ และอาจเขียนทับไฟล์ค่ากลยุทธ์กับรายงานเมื่อรัน
